A one-star review of Monday, written as though Monday were a restaurant. The entry is a single line about the wait, the food, the service, and the ambience:

> Booked 9 a.m., seated 9:45. Cold coffee, sighing waiter, gray ambience. The 'fresh start' special? Last week's leftovers. One star.

## Run it

```sh
node main.ts
```
